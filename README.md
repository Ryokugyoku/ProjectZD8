# ProjectZD8

ProjectZD8 is a SwiftUI and SwiftData application for Apple platforms.

## Requirements

- Xcode 26.4 or later
- iOS 26.4 or later, or macOS 26.4 or later

Open `ProjectZD8.xcodeproj` in Xcode to build and run the app.
